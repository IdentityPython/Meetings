IdPy Worksteam: DOCUMENTATION
====================================

This folder contains meeting notes and artifacts for the workstream discussing the **Prioritized Documentation Roadmap**.

## Invited Participants (9)
*Shayna Atkinson, Hannah Sebuliba, Nanyonga Rahmah, Ivan Kanakarakis, Derrick Ssemanda, Matthew Economou, Elliott Elrod, Vlad Mencl, Shannon Roddy, Laura Paglione*

> _**Want to participate?** [RSVP](https://www.addevent.com/event/v1pxwkxqqtf0/?embed=true&embedshare=no) to register for the working group meetings._

## KEY DELIVERABLES IN SCOPE
* Outline of the documentation content that is needed
* Prioritized documentation roadmap for each project repo
* Guidelines to outline the documentation approach <br/> *(documentation relationship to code, content guidelines, documentation categories --- technical manual vs case studies etc), etc)*

> ***Not in scope**: Detailed rules, guidance, or requirements related to the governance of documentation. Governance will generally be handled by the [Governance Workstream](../Workstream-Governance), though the Documentation Workstream is welcome to submit findings to the Governance Workstream to inform their work.*

## GOALS
* Make it easy to deploy the tools
* Help developers understand how to use the libraries
* Automate doc publishing alongside automated releases
* Better branding | and get rid of RTD!
* Support modern IDEs | Yes and that includes Emacs!

## TASKS
* Scope out how hard adding type hints will be
* Figure out how linters might help enforce good documentation
* Gain access to GitHub repository for review
