IdPy Worksteam: GOVERNANCE
==================================

This folder contains meeting notes and artifacts for the workstream discussing the **Technical Governance Workflow**.

## Invited Participants (11)
*Alessandro, Elliott, Hannah, Ivan, Laura, Nanyonga, Derrick, Matthew, Robin, Vlad, Federico*

## KEY DELIVERABLES IN SCOPE
* Defined and functioning maintainer model
  * Documentation release process
  * Documented contributor guidelines
* Documented technical governance workflow
  * Vulnerability report process
  * Clear contributor ladder
* Regular technical coordination meetings in operation

## GOALS
* Releasing can be done easily and often
* Any authorized maintainer or group can cut a release
* Automate releases
* Facilitate SCA/SBOM
* OIDC Trusted publishing workflow
* Coding standards implemented as automated quality gates
